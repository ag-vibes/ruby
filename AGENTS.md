# Vita

`project-context.md` — источник истины для продукта.

- не добавлять возможности за пределами MVP;
- интерфейсные тексты сохранять на русском языке и в нижнем регистре;
- использовать только палитру Vita из спецификации, не палитру Cushion;
- Cushion служит референсом архитектуры и базовых UI-паттернов;
- хранить данные локально в существующей IndexedDB `ruby` для сохранения пользовательских данных после переименования приложения;
- сохранять ввод и отображение десятичных значений через запятую;
- после изменений запускать `npm test` и `npm run build`.
